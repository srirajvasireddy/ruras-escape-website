# Rura style artwork

Drop character art here using the filenames referenced in
`src/data/cosmetics.ts`:

```
rura-classic.webp
rura-biker.webp
rura-joker.webp
rura-christmas.webp
rura-halloween.webp
rura-football-pro.webp
```

Guidelines:

- Square images (the showcase crops to `aspect-square`), 600 x 600 is plenty.
- Transparent or dark backgrounds sit best against the midnight page.
- Missing files fall back to a placeholder frame, so styles can be added one at
  a time.
